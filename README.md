# UT-BookShop 📚

UT-BookShop is a full-stack, responsive web application built with Python and Django. Designed for students and avid readers, the platform allows users to seamlessly browse cataloged books, manage shopping carts, handle authentication, and generate dynamic PDF receipts/documents.

🚀 **Live Demo:** [https://ut-bookshop.onrender.com](https://ut-bookshop.onrender.com)

---

## 🌟 Key Features

* **Book Catalog:** Filter and search books by title, author, or category.
* **User Authentication:** Secure registration, login, and user session management.
* **Shopping Cart & Checkout:** Add/remove items, update quantities, and simulate orders.
* **Dynamic PDF Generation:** Built-in PDF export features powered by `xhtml2pdf`.
* **Clean & Responsive UI:** Styled with Bootstrap & Crispy Forms for mobile and desktop screens.
* **Production Ready:** Configured with WhiteNoise for static asset management and Gunicorn for WSGI production hosting.

---

## 🛠️ Tech Stack

* **Backend:** Python, Django
* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 4, Django Crispy Forms
* **Static Assets & PDF Handling:** WhiteNoise, `xhtml2pdf`
* **Production Server:** Gunicorn
* **Deployment & Hosting:** GitHub, Render
